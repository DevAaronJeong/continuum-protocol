# continuum-protocol

**Aligning people and work by rhythm, not resumes.**

[![Korean](https://img.shields.io/badge/Language-Korean-blue.svg)](README.kr.md)

`continuum-protocol` is an open-source experiment that explores how people and work can align through lifestyle, rhythm, and consistency — without ranking jobs, people, or careers.

We treat work not as a fixed identity, but as a temporary role within a person’s life continuum.

---

## What this is
- A **protocol**, not a platform
- A **continuous alignment system**, not one-time matching
- A **framework** for exploring work as a life state

This project does **not** define good or bad jobs. It focuses only on whether a person and an activity align *right now*.

---

## The Conceptual Model
We propose modeling Humans ($H$) and Work ($W$) as dynamic vectors, not static text.

$$Alignment(t) = f(H_{rhythm}(t), W_{rhythm}(t))$$

Where:
* $t$ is the current moment (implying change over time)
* $rhythm$ includes energy cycles, focus span, and social density.

We are actively looking for the right parameters to populate this function.

(See `src/prototype.py` for a basic Python implementation of this vector logic.)
