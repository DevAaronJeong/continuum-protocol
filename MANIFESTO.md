# Manifesto

There are no good or bad jobs.
There are only alignments — and misalignments — in time.

Lifestyle is not a ranking.
Work is not an identity.
Careers are not linear paths.

Work is a role we step into,
learn from,
and step out of.

This project exists to support transitions,
not to optimize careers.

Alignment is temporary.
Leaving is natural.
Consistency is effort.
Effort deserves respect.
